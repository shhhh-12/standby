# StandBy for Android (OnePlus 13)

Build the APK
1. Install Android Studio, then File > Open > this folder. Let Gradle sync.
2. Build > Build APK(s)  (debug)  — or Build > Generate Signed App Bundle / APK.
   APK ends up in app/build/outputs/apk/debug/app-debug.apk
3. Copy to the phone and install (allow "install unknown apps").

First run (in the app)
1. Allow display over other apps  2. Allow notifications
3. Don't restrict battery  4. Turn StandBy ON
Also on OnePlus: Settings > Battery > App battery management > StandBy > Allow background activity.

Use
Plug in the charger, turn the phone on its side with the screen on -> StandBy opens.
Swipe up/down: Digital / Analog / Float / Widgets. Long-press: accent colour.
Dark room: dim red night mode. Back or Home exits until you re-plug or re-rotate.
